# Contributing

Bug reports and focused pull requests are welcome. For larger changes, open an issue first so scope and compatibility can be discussed.

## Development

```sh
npm ci
npm run build
```

Press `F5` in VS Code to launch the Extension Development Host. Include the VS Code version and manual validation details in pull requests that change behavior; a successful build alone does not establish broad file compatibility.

## Reports and data

Include the extension version, VS Code version, operating system, file format, and redacted reproduction steps. Do not attach real spreadsheets, API logs, access tokens, personal data, or proprietary workspace contents. Use a minimal synthetic file when an example is needed.

The maintainer decides what is accepted and released. Contributions should preserve the existing MIT license and include attribution for third-party assets or code.
